# AI Tools Used

## ChatGPT
Purpose: architecture planning, React/Express implementation, debugging and requirement tracking.

Example prompt:
> Build a reusable React architecture for a premium Riyadvi corporate site with dynamic service, portfolio, blog and career routes, an interactive 3D hero and an Express/MongoDB backend.

Generated: component structures, route patterns, API patterns, debugging guidance and documentation drafts.

Manual changes: corrected CSS parser errors, rewired middleware, added validation, created the six-step health checkup, integrated the lead magnet download, added admin access handling and adjusted the visual system to match the assignment requirements.

Why selected: fast iteration across frontend, backend, debugging and documentation.

## Bolt / AI website generation workflow
Purpose: rapid visual exploration and initial UI direction.

Generated: early layout concepts and styling ideas.

Manual changes: the final architecture was rebuilt around reusable React components, dynamic data, Express APIs and MongoDB instead of submitting an unmodified generated template.

## AI-generated 3D exploration
Purpose: explore interactive technology/business visual metaphors.

Manual changes: constrained geometry, device pixel ratio and animation workload to keep the experience usable on smaller devices.
